# Task: max_subarray

Implement a function with this exact signature in `solution.py`:

```python
def max_subarray(nums):
    ...
```

**Spec:** Given a list of integers `nums` with at least one element (values may be negative),
return the largest possible sum of a contiguous, non-empty subarray of `nums`.

**Constraints:**
- `len(nums) >= 1`.
- The subarray must be non-empty and contiguous.
- Aim for O(n) time (Kadane's algorithm).
