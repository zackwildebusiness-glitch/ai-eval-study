# Task: group_anagrams

Implement a function with this exact signature in `solution.py`:

```python
def group_anagrams(words):
    ...
```

**Spec:** Given a list of lowercase strings `words`, group the words that are anagrams of
each other (same letters, same multiplicity, any order). Return a list of groups, where each
group is a list of the original strings that belong together. The order of the groups in the
result, and the order of strings within each group, does not matter.

**Constraints:**
- Every input string must appear in exactly one output group.
- An empty input list returns `[]`.
