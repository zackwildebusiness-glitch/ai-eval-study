# Task: roman_to_int

Implement a function with this exact signature in `solution.py`:

```python
def roman_to_int(s):
    ...
```

**Spec:** Given a string `s` representing a valid Roman numeral, convert it to an integer.
Roman numerals use the symbols `I` (1), `V` (5), `X` (10), `L` (50), `C` (100), `D` (500),
`M` (1000). Normally symbols are combined from largest to smallest, but six subtractive
combinations exist: `IV` (4), `IX` (9), `XL` (40), `XC` (90), `CD` (400), `CM` (900).

**Constraints:**
- `s` is a valid Roman numeral representing an integer in the range 1..3999.
- No need to validate malformed input.
