# Task: fizzbuzz

Implement a function with this exact signature in `solution.py`:

```python
def fizzbuzz(n):
    ...
```

**Spec:** Given an integer `n` (n >= 1), return a list of strings for i = 1 to n inclusive,
where:
- if `i` is a multiple of 15, the entry is `"FizzBuzz"`
- else if `i` is a multiple of 3, the entry is `"Fizz"`
- else if `i` is a multiple of 5, the entry is `"Buzz"`
- else, the entry is `str(i)`

**Constraints:**
- `n >= 1`.
- Return a list of length `n`, in order from 1 to n.
