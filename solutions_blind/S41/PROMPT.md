# Task: move_zeroes

Implement a function with this exact signature in `solution.py`:

```python
def move_zeroes(nums):
    ...
```

**Spec:** Given a list of integers `nums`, move all `0`s to the end of the list while
preserving the relative order of the non-zero elements. Return the resulting list.

**Constraints:**
- Preserve relative order of non-zero elements.
- All zeros end up at the end, in the same count as the input.
- An empty list returns `[]`.
