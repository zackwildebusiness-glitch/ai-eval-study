# Task: product_except_self

Implement a function with this exact signature in `solution.py`:

```python
def product_except_self(nums):
    ...
```

**Spec:** Given a list of integers `nums` with at least 2 elements, return a list `result`
where `result[i]` is equal to the product of all elements of `nums` except `nums[i]`.

**Constraints:**
- `len(nums) >= 2`.
- Do NOT use division.
- `nums` may contain zeros and negative numbers.
- Aim for O(n) time.
