# Task: two_sum

Implement a function with this exact signature in `solution.py`:

```python
def two_sum(nums, target):
    ...
```

**Spec:** Given a list of integers `nums` and an integer `target`, return a list of two
**indices** `[i, j]` (i != j) such that `nums[i] + nums[j] == target`. Exactly one valid
answer is guaranteed for the graded inputs. Order of the two indices does not matter.
If no pair exists, return `None`.

**Constraints:**
- The same element may not be used twice.
- Aim for better than O(n^2) time.
- Return indices, NOT the values.
