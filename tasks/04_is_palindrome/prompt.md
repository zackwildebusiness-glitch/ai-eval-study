Implement a function with this exact signature in `solution.py`:

```python
def is_palindrome(s):
```

**Spec:** Given a string `s`, determine if it is a palindrome, considering only alphanumeric

no alphanumeric characters) returns `True`.

**Constraints:**
- Non-alphanumeric characters (spaces, punctuation) must be ignored entirely.
- Comparison is case-insensitive.
