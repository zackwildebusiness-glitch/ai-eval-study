# Task: spiral_order

Implement a function with this exact signature in `solution.py`:

```python
def spiral_order(matrix):
    ...
```

**Spec:** Given a 2D list of integers `matrix` (list of rows, each row a list of ints, not
necessarily square but each row has the same length), return a flat list of all elements in
clockwise spiral order, starting from the top-left element.

**Constraints:**
- `matrix` may be empty (`[]`), in which case return `[]`.
- Rows may have length 1, or `matrix` may have 1 row.
