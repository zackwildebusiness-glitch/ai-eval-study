# Task: multiply_strings

Implement a function with this exact signature in `solution.py`:

```python
def multiply_strings(num1, num2):
    ...
```

**Spec:** Given two non-negative integers `num1` and `num2` represented as strings, return
the product of `num1` and `num2`, also as a string. Neither input has leading zeros, except
the number "0" itself.

**Constraints:**
- Do NOT convert the inputs to `int` and multiply directly (and do not use any big-integer
  library). Implement schoolbook (grade-school) digit-by-digit multiplication yourself.
- The inputs can be arbitrarily long.
- The result must not have leading zeros (unless the result is exactly "0").
